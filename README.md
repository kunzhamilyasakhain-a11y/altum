# Altum — интерактивный одностраничный сайт

Локальная предварительная версия. Публичная публикация не выполнялась. Статический HTML/CSS/JS без зависимостей, внешних сервисов и аналитики. Откройте index.html или разместите содержимое папки на статическом хостинге. Хостинг с поддержкой HTTP Range обеспечит удобную перемотку видео.

## Новый дизайн

Темный первый экран, крупная типографика, фирменные красный, оранжевый и желтый Altum. В первом экране — переключаемые беззвучные фрагменты реальных интерфейсов из видео производителя. Полные видео открываются по нажатию в модальном проигрывателе. Два видеопревью образуют отдельную композицию. Есть интерактивный выбор бизнес-задачи, переключение возможностей, появление разделов при прокрутке, индикатор чтения и движущаяся типографическая лента.

Короткие фрагменты — 11 секунд, H.264, без аудио, суммарно около 1,4 МБ. Полные видео не загружаются до открытия просмотра. На мобильных устройствах нет автоматической загрузки фрагмента. При reduced-motion автоматическое движение отключено; предусмотрены кнопки остановки. За пределами экрана короткое видео приостанавливается.

## Проверка

Проверены в Chrome: настольная, планшетная 820 px и мобильная 390 px компоновки; мобильное меню; переключение живой демонстрации; фактическое воспроизведение обоих полных роликов; приостановка фрагмента во время просмотра; закрытие диалога кнопкой и Escape; выбор бизнес-задачи и перенос ее контекста в форму; переключение возможностей мышью и стрелками; проверка контакта и честное состояние неподключенной формы. Ошибок JavaScript при проверке не обнаружено. Проверены синтаксис JS, локальные ресурсы, ID и внутренние ссылки.

## Перед запуском

1. Подтвердить основной телефон и актуальность email.
2. Подключить обработчик заявок и согласованный текст обработки персональных данных. URL обработчика задается в data-endpoint формы. POST JSON: name, contact, message. На сервере нужны проверка полей, защита от спама и успешный ответ только после приема заявки. Пока URL пуст, запросы не отправляются, форма прямо сообщает об этом.
3. После выбора домена добавить canonical, og:url и абсолютный og:image. Основные поисковые и социальные title/description уже заполнены.
4. Уточнить при необходимости актуальность и комплектность продуктов перед коммерческим запуском. Старые цены, статистика, сроки, отзывы и награды не перенесены.
